<a name="português"></a>
## 🇧🇷 Português

Um portal web informativo desenvolvido durante o curso Técnico em Desenvolvimento de Sistemas (SESI/SENAI-SP), dedicado a apresentar a história, as regras básicas e curiosidades sobre o universo do Xadrez.

🔗 **Acesse o projeto online:** [brunossilva12-creator.github.io/PaginaWebCuriosidades](https://brunossilva12-creator.github.io/PaginaWebCuriosidades/)

### ✨ Funcionalidades e Seções
- **Navegação Multipáginas:** Menu superior estruturado com acesso às seções **Home**, **Jogar**, **Curiosidades** e **Fale Conosco**.
- **História e Origem:** Narrativa sobre a lenda do criador Sissa e o desafio matemático dos grãos de trigo no tabuleiro de 64 casas.
- **Guia Básico de Regras:** Explicação sobre a função de cada peça, movimentos especiais (como o *en-passant*), diagrama do tabuleiro e vídeo tutorial incorporado.
- **Recomendações Extras:** Indicações culturais relacionadas ao tema, como a série *O Gambito da Rainha*.
- **Acesso Externo para Partidas:** Atalho direto para praticar xadrez online contra o computador.

### 🛠️ Tecnologias Utilizadas
- **HTML5:** Estruturação semântica de textos, mídia incorporada (vídeos e imagens) e navegação entre páginas.
- **CSS3:** Estilização visual, organização de layout, tipografia e responsividade.

### 🚀 Como executar localmente
1. Clone este repositório:
   ```bash
   git clone https://github.com/brunossilva12-creator/PaginaWebCuriosidades
   ```
2. Abra a pasta do projeto e execute o arquivo `index.html` diretamente no seu navegador.

<a name="english"></a>
## 🇺🇸 English

An informative web portal developed during the Systems Development Technical Course (SESI/SENAI-SP), dedicated to presenting the history, basic rules, and interesting facts about Chess.

🔗 **Live Demo:** [brunossilva12-creator.github.io/PaginaWebCuriosidades](https://brunossilva12-creator.github.io/PaginaWebCuriosidades/)

### ✨ Features & Sections
- **Multi-Page Navigation:** Top navigation bar connecting **Home**, **Play**, **Curiosities**, and **Contact** pages.
- **History & Origin:** Overview of the classic legend of Sissa and the exponential wheat-grain chessboard puzzle.
- **Beginner's Rule Guide:** Breakdown of piece movements, special rules (such as *en-passant*), board setup, and embedded video tutorials.
- **Extra Recommendations:** Cultural suggestions related to chess, including the series *The Queen's Gambit*.
- **External Play Link:** Direct shortcut to play chess online against the computer.

### 🛠️ Technologies Used
- **HTML5:** Semantic content structure, embedded media (videos and images), and multi-page linking.
- **CSS3:** Visual styling, layout organization, typography, and responsive design.

### 🚀 How to run locally
1. Clone this repository:
   ```bash
   git clone https://github.com/brunossilva12-creator/PaginaWebCuriosidades
   ```
2. Open the project folder and launch the `index.html` file in your browser.
